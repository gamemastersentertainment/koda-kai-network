# Verification

MANIFEST.sha256: every file of the move, fingerprinted before anything was copied. A file that differs after the copy is listed CHANGED with its reason on the row, never silently fixed. Zero unexplained CHANGED rows is a signing condition.

UNFINISHED.md: the register of builds started and never finished, each verdicted — DORMANT, LEANED-ON, HALF-WIRED, or FINISH-FIRST. Dave's World reflects it, so anyone walking the duplicate can see which rooms are load-bearing and which are still scaffolding.

The signing tests live here too. Nothing in this repository is claimed beyond what this directory can prove.
