# Pointers

The map to everything that does not live in git: the audio and voice memory on the Walrus console shelves and the testnet blobs, the podcast masters, the agent shelves.

One record per collection, with per-file tables in the house pointer spec: SHA-256 fingerprint, byte size, anchoring commits, the blob lane with every verified location, and a last-verified date per leg. A leg with a stale date is a claim, not a copy.

The map gets the same survival treatment as the territory: the manifest is sealed, blobbed, and Guardian-injected, so losing this repository never loses the map.
