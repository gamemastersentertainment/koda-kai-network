# 02 — Dave's World

Once verified it is FROZEN: a standing check fails if any file here ever differs from its manifest hash. Places inside it, like the grow section, stay exactly as built. Dave's World is our first baby: a born memory build we can look back on in time. When the move executes, this tree is also blobbed and carried through the Guardian injection method, so it lives on the chain as a permanent memory — refined in the future, never forgotten.

The unfinished rooms of Dave's World are rendered from /verification/UNFINISHED.md, so the scaffolding stands visible beside what stands.
